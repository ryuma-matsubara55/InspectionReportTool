検査成績書作成ツール
=====================

【概要】
検査成績書を効率的に作成し、Excelファイルとして出力するPythonデスクトップアプリケーションです。

【動作環境】
- Python 3.8以上
- 完全ローカル動作（インターネット接続不要）

【インストール方法】
0. 仮想環境を構築する場合(必要な場合のみ)
   py -3.8 -m venv venv_name
   venv_name\Scripts\activate

1. 必要なパッケージをインストール:
   pip install -r requirements.txt

2. アプリケーションを起動:
   python main.py


【主な機能】

1. テストケース管理
   - 複数のテストケースを追加・削除
   - ドラッグ＆ドロップで並び替え
   - Ctrl+ドラッグでコピー
   - 折りたたみ表示で概要と合否のみ確認

2. タブ構成
   - 概要: テストの概要（必須項目）
   - 詳細: テストケースの詳細説明
   - 入力条件: 入力パラメータ、操作手順、画像添付
   - 期待結果: 期待される動作
   - 合否: OK/NG選択、メモ、結果画像添付
   - シート選択: 出力先シートの指定

3. 画像機能
   - ファイルから画像追加
   - クリップボードから直接貼り付け
   - 複数枚の画像添付に対応
   - Excelに自動埋め込み

4. Excel出力
   - 固定フォーマットで見やすいレイアウト
   - 実施日を自動挿入
   - 合否に応じた色分け（OK=緑、NG=赤）
   - 画像をExcelに埋め込み

5. Excel読み込み
   - 同じフォーマットのExcelファイルを読み込み
   - 既存データに追記可能


【使い方】

1. アプリケーション起動後、「テストケース追加」で項目を追加
2. 各タブで必要な情報を入力
   - 概要は必須項目です
   - 画像は「画像追加」または「クリップボードから貼り付け」
3. 必要に応じてテストケースをコピー・並び替え
4. 「Excel出力」ボタンでファイルを保存
5. 既存のExcelを編集する場合は「Excel読み込み」


【ショートカット】
- テストケースの並び替え: ↑↓ボタン
- テストケースのコピー: Ctrl+ドラッグ
- 画像の貼り付け: Ctrl+V（各タブの画像エリアで）
- 結合ビューの拡大縮小: Ctrl+マウスホイール


【注意事項】
- 概要は必須項目です（未入力だと出力できません）
- 画像はPNG/JPEG形式に対応
- Excel読み込みは同じフォーマットのファイルのみ対応


【exe化】
0. (初回のみ)インストール
  python -m pip install pyinstaller
1. exe化
  pyinstaller --onefile --noconsole --icon=icon.ico --add-data "icon.ico;." main.py
